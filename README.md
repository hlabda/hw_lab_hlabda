# Lab 04 SimpleBrowser

**Platform:** Swift (SwiftUI)

SimpleBrowser is a compact iPhone web browser built with SwiftUI and WebKit. It includes:

- A URL field that accepts addresses with or without `https://`
- A `WKWebView` for displaying web pages
- Back and forward navigation
- Share, reload, and stop controls
- Swipe navigation gestures
- Unit and UI tests for URL handling and the browser controls

## Run the app

1. Open `SimpleBrowser.xcodeproj` in Xcode.
2. Select an iPhone simulator.
3. Run the `SimpleBrowser` scheme.
4. Enter a URL and press **Go** on the keyboard or tap the arrow button.
