# BookManager

**Platform: Swift (SwiftUI)**

BookManager is the completed SwiftUI app for Lab 03. It uses a shared in-memory library of 77 classic books and includes:

- A tab-based Library, New Book form, and Charts screen
- Alphabetically sorted book records
- Book details and swipe-to-delete support
- Form validation, confirmation, and automatic clearing after submission
- Charts for author gender and five popular authors
- Unit tests for the model and library behavior
- An end-to-end UI test for adding a new book

## Run the app

1. Open `BookManager.xcodeproj` in Xcode.
2. Choose an iPhone simulator.
3. Press Run.

## Run the tests

In Xcode, choose **Product > Test** or press **Command-U**.
