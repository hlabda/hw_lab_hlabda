# Space Destroyers

An Expo and TypeScript arcade game for Lab 10. Tilt the phone to steer and tap the playfield to fire. Each invader is worth 10 points. Clear three waves with three lives before the invaders reach the bottom. Only the lowest surviving invader in each column can shoot back.

## Run

With Node.js 22 LTS (22.13 or newer in the 22.x series), run

```sh
npm ci
npm start
```

Open the project in Expo Go for SDK 58 on an iOS or Android phone. Allow motion access when prompted. The phone and development computer should be on the same network.

## Check

```sh
npm run typecheck
npm test
```
